# one-ui-factory

Status: **UI FACTORY** · web, desktop, and iOS

Gate → inventory → tokens → compose → adapt → craft → critique → verify the running UI.
Do not invent a second process per platform.

## Compose (avoid default agent looks)

Avoid: Generic Inter + purple gradient, identical cards, empty-state illustrations that mean nothing, generated journal sample copy, typeface chips, near-vertical fibre that reads as pinstripe, system-gray “dark mode” that Notes-ifies a paper product.

Empty copy is product voice. One word is enough (**Empty**). Sample pages should sound like a person (a name, a list), not a generated journal.

## Verify

Drive the running UI. Screenshot. Do not pass from code alone.
On iOS, if dark mode shipped this turn, look at light **and** dark. Night desk, cream sheets stay cream.

## Don't

Don't make Art director mandatory on every screen. Don't invent a separate slop skill. Slop lives here and in `ui-thrift`.
