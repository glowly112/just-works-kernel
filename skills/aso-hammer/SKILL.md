# aso-hammer

Use after store-list. Pair with verify-done: live iTunes GB + US and a character count this turn.

Fail code: `ASO_FAIL`. Any miss is a fail. Do not invent ranks.

## Glare list (all)

1. **Job.** It is X. It is not Y.
2. **Name says the job.** Brand-only one word is allowed only if the subtitle states X on its own.
3. **Live collision.** Exact title clear on iTunes GB + US this turn.
4. **Limits.** Name ≤30, subtitle ≤30, keywords ≤100. No spaces after commas.
5. **Hygiene.** No name/subtitle word in keywords. No competitor names, “app”, extra plurals.
6. **First sentence.** Description opens with the job line.
7. **Screenshot story.** Open → type → result. App in use, not title art.
8. **URLs + home name.** Privacy URL and support URL exist. Home-screen display name matches the locked listing name.

## Don’t

- Don’t pass on a plan
- Don’t install aso-skill or rank trackers
- Don’t submit App Review from this skill
