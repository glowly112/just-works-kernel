# store-list

Use when they talk listing or ASO. After store-research and store-fit. Then aso-hammer must pass before anyone says done. en-GB unless they say otherwise.

Load live listing limits and Review 2.3 from https://developer.apple.com/app-store/product-page/ this turn.

## 1. What it is

Restate the job in one line from the product. Write: it is X. It is not Y.

Prefer one word only when that word still says the job and is search-clear. Two words if the one word is brand-only or already owned in search.

Live-check the exact title and the first token on iTunes GB + US this turn. Title-clear is not search-clear.

When they lock a listing name, set the home-screen display name (`CFBundleDisplayName`) in the **same** ship. Listing-only is not the name change.

## 2. Indexed

- Name 30
- Subtitle 30
- Keywords 100 — commas, no spaces after them

Do not repeat a name/subtitle word in keywords. No competitor names, category names, “app”, or extra plurals. Description and promo are not indexed.

## 3. Listing

- First sentence repeats the job line
- Screenshot story: open → type → result
- Privacy URL and support URL before Review

## Don’t

- Don’t invent ranks
- Don’t install aso-skill or rank trackers
- Don’t submit App Review from this skill
- Don’t leave the home-screen name on the old title after they locked a new one
